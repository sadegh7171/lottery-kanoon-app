کانون فرهنگی هنری سالارشهیدان مسجد امام حسین (ع) - کوی ابوذرغفاری - شهرستان شوش دانیال (ع)

## ساخت APK با گوشی
1. کل پوشه پروژه را در یک مخزن GitHub با نام `lottery-kanoon-salarshohada` قرار دهید.
2. وارد بخش Actions شوید.
3. گردش‌کار `Build Android APK` را انتخاب کنید.
4. گزینه `Run workflow` را بزنید.
5. بعد از پایان موفق، در بخش Artifacts فایل `MasjedEmamHossein-Lottery-APK` را دانلود کنید.
6. فایل ZIP دانلودشده را باز کنید و `app-release.apk` را روی گوشی نصب کنید.
